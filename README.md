# 🌱 Smart Plant Watering System

An Arduino-based Smart Plant Watering System that automatically waters plants using a soil moisture sensor, relay module, and water pump. The system monitors soil moisture continuously and supplies water only when required, helping reduce water wastage and maintain healthy plant growth.

---

## 📌 Project Overview

The Smart Plant Watering System is an automated irrigation project designed using Arduino Uno. It detects the moisture level of the soil and automatically turns the water pump ON when the soil becomes dry. Once the required moisture level is reached, the pump turns OFF automatically.

This project is suitable for home gardens, indoor plants, terrace gardens, and small-scale agricultural applications.

## ⚙️ Working Principle

1. The soil moisture sensor measures the moisture level.
2. Arduino continuously reads the sensor values.
3. If the soil is dry, Arduino activates the relay.
4. The relay switches ON the water pump.
5. Water is supplied to the plant.
6. Once the soil becomes sufficiently moist, the relay switches OFF the pump.
